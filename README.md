# EV Battery Degradation Prediction Using Charge Cycles & Temperature

## 📌 Project Overview
This project predicts battery degradation rate and battery health status in Electric Vehicles using Machine Learning and Neural Networks. The system analyzes operational parameters such as charge cycles and temperature to estimate remaining battery capacity and classify battery health.

---

## 🎯 Objectives
- Predict remaining battery capacity (%)
- Classify battery health (Good / Medium / Poor)
- Compare multiple ML regression and classification models
- Build a final prediction pipeline

---

## 📊 Features Used
- Charge Cycles
- Average Temperature
- Charge Rate
- Discharge Depth
- Battery Age (Months)
- Voltage Variation
- Battery Type
- Cooling System
- Usage Pattern

---

## 🤖 Models Implemented

### Regression Models
- Linear Regression
- Random Forest Regressor
- Support Vector Regression (SVR)

### Classification Models
- Decision Tree
- Random Forest Classifier
- Support Vector Machine (SVM)
- Neural Network (TensorFlow/Keras)
